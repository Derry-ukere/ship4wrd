# Ship4wd

A web project for Ship4wd — a digital freight forwarding platform that simplifies international shipping for small and medium-sized businesses.

## Branches

- `main` — base branch
- `production` — production-ready build with the latest features

## Features

- Auto translation support via Google Translate Widget
- Live chat integration
- Responsive design

## Getting Started

Open `index.html` in a browser to view the page locally.
